# LegalEase AI

**AI-Powered Legal Document Generator**

LegalEase AI is a web application that helps users generate draft legal documents using Artificial Intelligence.

## Features
- Generate draft legal documents using AI
- Support multiple document types
- Enter party names, effective dates, and terms
- Edit generated documents
- Download documents as text files

## Technologies Used
- Python
- Streamlit
- FastAPI
- Google Gemini AI

## Project Structure
- `backend/` – Backend API and AI integration
- `frontend/` – User interface
- `requirements.txt` – Required Python packages

## Disclaimer
This application generates draft documents for informational purposes only. It does not provide legal advice. Please consult a qualified lawyer before using any generated document.
